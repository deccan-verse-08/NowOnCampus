# NowOnCampus 🎓

**NowOnCampus** is a comprehensive event management platform designed for college students and organizers. It centralizes all campus events—from hackathons to cultural fests, sports tournaments, and workshops—into one accessible place. Students can easily discover, register for, and track their events, while administrators have the tools to seamlessly create, manage, and oversee them.

## 🚀 Features

### For Students:
* **Event Discovery:** Browse a categorized and sortable list of all upcoming, ongoing, and past events.
* **Easy Registration:** One-click registration for events (if spots are available and the deadline hasn't passed).
* **Two-Step OTP Login:** Secure login flow using an email-delivered one-time password (OTP) instead of a traditional password. 
* **Seamless Google OAuth:** Quick sign-in using your Google account via NextAuth.
* **Dashboard & Profile:** A beautifully designed profile dashboard to view all your registered events, statistics, and account details.

### For Administrators:
* **Event Management:** Create, edit, and delete events with details like date, venue, max participants, team sizes, prize money, and categorization.
* **Registration Tracking:** View and manage a comprehensive list of all event registrations.
* **User Management:** View all users, assign roles, and remove accounts if necessary (includes automatic handling of decremeting event participant counts upon deletion).
* **Secure Admin Access:** All admin routes and API endpoints are strictly protected.

## 💻 Tech Stack

* **Framework:** [Next.js 15](https://nextjs.org/) (App Router format)
* **Language:** [TypeScript](https://www.typescriptlang.org/)
* **Styling:** [Tailwind CSS v4](https://tailwindcss.com/)
* **Database Interfacing & ORM:** [Prisma](https://www.prisma.io/)
* **Database Setup:** PostgreSQL (Neon DB recommended)
* **Authentication:** [NextAuth.js v5 (Auth.js)](https://authjs.dev/)
* **Email / OTP Sending:** [Nodemailer](https://nodemailer.com/)
* **Icons:** [Lucide React](https://lucide.dev/)
* **Validation:** [Zod](https://zod.dev/)

## 🛠️ Local Development Setup

To get this project running locally on your machine, follow these steps:

### 1. Clone the repository
\`\`\`bash
git clone https://github.com/your-username/nowoncampus.git
cd nowoncampus
\`\`\`

### 2. Install Dependencies
\`\`\`bash
npm install
\`\`\`

### 3. Environment Variables
Create a `.env` file in the root directory and add the following keys:

\`\`\`env
# Database URL (Prisma)
DATABASE_URL="postgresql://username:password@hostname/dbname?sslmode=require"

# NextAuth / Auth.js
NEXTAUTH_URL="http://localhost:3000"
NEXTAUTH_SECRET="your-generated-random-secret" # Run `npx auth secret`

# Google OAuth Credentials
GOOGLE_CLIENT_ID="your-google-client-id"
GOOGLE_CLIENT_SECRET="your-google-client-secret"

# Nodemailer Settings (For OTP / Emailing)
GMAIL_USER="your-email@gmail.com"
GMAIL_PASS="your-gmail-app-password" # Generate an App Password in Google Account Security
EMAIL_FROM="NowOnCampus <your-email@gmail.com>"
\`\`\`

### 4. Database Setup (Prisma)
Push the Prisma schema to your configured database:
\`\`\`bash
npx prisma db push
\`\`\`

*(Optional)* Seed the database with an initial Admin user if required, or simply register a new account on the frontend and manually change the role to `"ADMIN"` in your database viewer.

### 5. Run the Local Development Server
\`\`\`bash
npm run dev
\`\`\`
The application will be running at [http://localhost:3000](http://localhost:3000).

## 🏗️ Deployment (Vercel)

NowOnCampus is fully optimized for deployment on [Vercel](https://vercel.com/).

1. Push your code to a GitHub repository.
2. Import the project into Vercel.
3. Add all the Environment Variables listed above into the Vercel project settings.
4. Set the Custom Install Command to `npm install` and the Build Command to `npm run build`.
5. Deploy!

*(Note: Vercel usually handles the `next build` command out of the box. Ensure the Prisma Client is generated by ensuring `"postinstall": "prisma generate"` is kept in your `package.json` scripts.)*
